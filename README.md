# Gender Detection by Names (with Temporary CRUD)

This project predicts whether a given person's name is **Male** or **Female**. It features a temporary data management system to add, update, view, and delete names in real-time memory.

## 🚀 Core Features
- **Gender Prediction:** Instantly identifies gender based on name patterns.
- **In-Memory CRUD:** Perform temporary operations on the names list:
  - **Create:** Add new names to the temporary list.
  - **Read:** View all stored names and their predicted genders.
  - **Update:** Modify existing names in the list.
  - **Delete:** Remove names from the list instantly.
- **Volatile Storage:** Resetting or restarting the application clears the temporary session data.

## 🛠️ Tech Stack
- **Language:** Python / JavaScript (Mee language ni batti idi modify cheyandi)
- **Data Storage:** Local State / In-Memory Lists (No permanent database used)

## 💻 How to Run & Test

1. Open your terminal or browser console.
2. Run the application script.
3. Use the menu/buttons to add a name, update it, see the gender output, or delete it from the temporary screen.
